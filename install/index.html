Chrome에서 열어 주세요

안에서는 홈 화면 설치가 안 돼요. 아래 버튼을 누르면 Chrome으로 이동해요.

Chrome에서 열기
버튼을 눌러도 안 열리나요?
  1. 화면 오른쪽 위 ⋮ 또는 ··· 메뉴를 눌러요
  2. ‘다른 브라우저로 열기’를 눌러요
  3. Chrome이 열리면 이 화면에서 이어서 설치해요

Safari에서 열어 주세요

안에서는 홈 화면에 추가할 수 없어요. Safari로 옮겨서 이어서 해요.

Safari로 열기
  1. 화면 오른쪽 아래 ··· 또는 공유 버튼을 눌러요
  2. ‘Safari로 열기’ 또는 ‘기본 브라우저로 열기’를 눌러요
  3. Safari가 열리면 이 화면에서 이어서 설치해요

메뉴를 찾기 어렵다면 주소를 복사해서 Safari 주소창에 붙여넣으세요.

Chrome 메뉴에서 설치해요

아래 순서대로 누르면 1분이면 끝나요.

  1. 오른쪽 위 ⋮ 메뉴를 눌러요
  2. 메뉴를 아래로 내려 ‘설치 및 바로가기 만들기’ (또는 ‘앱 설치’, ‘홈 화면에 추가’)를 눌러요
  3. ‘설치’를 누르고, 확인 창에서 한 번 더 ‘설치’를 눌러요
  4. 홈 화면에 아이콘이 없다면 앱 목록에서 Verbum을 길게 눌러 ‘홈 화면에 추가’
